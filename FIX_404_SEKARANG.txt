SOLUSI: Clear route cache!

═══════════════════════════════════════════════════════════════════════════
   🔧 CARA PALING CEPAT - RAILWAY SHELL
═══════════════════════════════════════════════════════════════════════════

1. Buka Railway Dashboard: https://railway.app
2. Pilih project "Archofesa"
3. Klik tab "Shell" (ikon terminal)
4. Copy-paste command ini (SELURUH BARIS):

php artisan route:clear && php artisan config:clear && php artisan cache:clear && php artisan view:clear

5. Tekan Enter, tunggu selesai (beberapa detik)
6. Test lagi:
   - Homepage: https://archofesa-production.up.railway.app
   - Test: https://archofesa-production.up.railway.app/diagnostic/basic

   📝 ATAU UPDATE railway.json MANUAL
═══════════════════════════════════════════════════════════════════════════

Jika Railway Shell tidak tersedia:

1. Edit file: railway.json
2. Ubah "releaseCommand" menjadi (tambahkan cache:clear di awal):

"releaseCommand": "php artisan cache:clear && php artisan route:clear && php artisan config:clear && php artisan view:clear && php artisan migrate --force && php artisan storage:link"

3. Save file
4. Git commit dan push:
   git add railway.json
   git commit -m "Fix route cache issue"
   git push origin main

5. Tunggu Railway deploy (~2 menit)
6. Test website lagi

═══════════════════════════════════════════════════════════════════════════
   💡 KENAPA INI TERJADI?
═══════════════════════════════════════════════════════════════════════════

Railway men-cache routes untuk performa. Saat kita push perubahan route baru
(diagnostic routes, test-railway.php), cache lama masih digunakan sehingga
route baru tidak terdeteksi.

Setelah clear cache, Railway akan reload semua routes dan halaman baru akan
bisa diakses.
