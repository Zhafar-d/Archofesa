4. Klik deployment paling atas (yang terbaru)
5. Scroll ke bawah, lihat bagian logs

CARI KATA-KATA INI DI LOGS:
- "ERROR"
- "FAILED"
- "Exception"
- "Fatal error"

═══════════════════════════════════════════════════════════════════════════
   LANGKAH 3: CEK ENVIRONMENT VARIABLES
═══════════════════════════════════════════════════════════════════════════

1. Railway Dashboard → tab "Variables"
2. Pastikan variable berikut ADA dan TERISI:

   ✅ APP_KEY (harus diisi, format: base64:xxxxx...)
   ✅ APP_ENV (isi: production)
   ✅ APP_URL (isi: https://archofesa-production.up.railway.app)
   
   ✅ DB_CONNECTION (isi: mysql atau pgsql)
   ✅ DB_HOST (otomatis dari Railway MySQL)
   ✅ DB_PORT (otomatis dari Railway MySQL)
   ✅ DB_DATABASE (otomatis dari Railway MySQL)
   ✅ DB_USERNAME (otomatis dari Railway MySQL)
   ✅ DB_PASSWORD (otomatis dari Railway MySQL)

   ✅ SESSION_DRIVER (isi: database)
   ✅ CACHE_STORE (isi: database)

   ✅ MIDTRANS_SERVER_KEY
   ✅ MIDTRANS_CLIENT_KEY
   ✅ MIDTRANS_IS_PRODUCTION (isi: false)

📸 SCREENSHOT variable list (boleh disensor value-nya, yang penting nama variablenya)

═══════════════════════════════════════════════════════════════════════════
   KEMUNGKINAN MASALAH & SOLUSI
═══════════════════════════════════════════════════════════════════════════

❌ MASALAH 1: APP_KEY tidak ada atau kosong
   SOLUSI: Generate APP_KEY baru
   - Di local, jalankan: php artisan key:generate --show
   - Copy hasilnya (format: base64:xxx...)
   - Tambahkan di Railway Variables → APP_KEY

❌ MASALAH 2: Database tidak terkoneksi
   SOLUSI: Pastikan Railway MySQL service sudah di-provision
   - Railway Dashboard → Add Service → MySQL
   - Variables database otomatis muncul

❌ MASALAH 3: Vite manifest not found
   SOLUSI: Build assets tidak jalan
   - Railway Settings → Build Command
   - Tambahkan: npm install && npm run build

❌ MASALAH 4: Migration belum jalan
   SOLUSI: Jalankan migration manual
   - Railway Shell: php artisan migrate --force

❌ MASALAH 5: Storage symlink tidak ada
   SOLUSI: Jalankan storage link
   - Railway Shell: php artisan storage:link
