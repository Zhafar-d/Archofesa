   🚨 CARA FIX 404 ERROR - SUPER SIMPLE! 🚨
═══════════════════════════════════════════════════════════════════════════

Masalah: Semua halaman Railway menampilkan 404 "Halaman tidak ditemukan"
Penyebab: Route cache di Railway masih menyimpan route lama

═══════════════════════════════════════════════════════════════════════════
   LANGKAH 1: BUKA RAILWAY SHELL
═══════════════════════════════════════════════════════════════════════════

1. Masuk ke https://railway.app
2. Klik project "Archofesa"
3. Klik tab "Shell" (ikon terminal) di bagian atas

═══════════════════════════════════════════════════════════════════════════
   LANGKAH 2: COPY-PASTE COMMAND INI DI RAILWAY SHELL
═══════════════════════════════════════════════════════════════════════════

Copy command ini (SELURUH BARIS):

php artisan route:clear && php artisan config:clear && php artisan cache:clear && php artisan view:clear

Paste di Railway Shell, tekan Enter, tunggu selesai.
